Patternodes

Generator for parametric graphic patterns and illustrations. Create generative designs, vector patterns, or animations using a node-based interface. Define sequences of connected nodes for graphical elements, transformations, and repetitions—parametric design meets visual scripting for 2D graphics.

Non-Destructive Workflow

Every node sequence is fully non-destructive. Tweak repetition counts, element properties, or any step instantly—see results update without redoing work. Perfect for iterative design.

Dynamic Connections

Link node parameters to create complex relationships. One property drives another, enabling intricate, interdependent designs that evolve with a single change.

Real-Time Animation

Animate parameters with keyframes in the timeline. Preview updates live, from static patterns to fluid motion, all within an intuitive interface.

Playful Experimentation

Built for discovery: real-time previews, inline help, warnings, samples, and a full manual guide you. Start simple, scale to sophisticated effortlessly.

How It Works

Step 1: Build Your Node Sequence

Drag nodes to define elements, changes, or repetitions. Connect them visually to form your parametric design.

Step 2: Tweak and Connect Parameters

Adjust properties non-destructively. Link parameters for relationships where one controls another dynamically.

Step 3: Animate with Keyframes

Add timeline keyframes to parameters. Watch live previews as your pattern or illustration comes alive.

Step 4: Preview and Export

Refine in real-time. Export high-quality vectors, patterns, or animations directly from the canvas.
